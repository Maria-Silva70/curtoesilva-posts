# curtoesilva-posts

Artes e vídeos da Curto e Silva (@curtoesilva), usados para publicar no Instagram.

- curtoesilva-posts/: imagens dos posts de outubro
- posts-novos/: novos posts, um por pasta, com as imagens e a legenda (legenda.txt)
- REELS/: vídeos e capas dos Reels
- stories/: imagens dos Stories
- fotos-maria/: fotos das obras, originais e editadas
- docs/: site publicado no GitHub Pages (atualizado a cada push na main)
